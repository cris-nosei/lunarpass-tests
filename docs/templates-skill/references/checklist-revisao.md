# Checklist de Revisão e Qualidade

Antes de considerar a tarefa concluída e entregar a resposta ao usuário, o agente deve verificar mentalmente cada um dos itens abaixo:

- [ ] Todos os requisitos explícitos foram atendidos?
- [ ] Nenhuma regra de negócio ou parâmetro foi inventado por suposição?
- [ ] As convenções de nomenclatura e estrutura do projeto foram rigorosamente seguidas?
- [ ] Arquivos fora do escopo da solicitação permaneceram intactos?
- [ ] Casos de erro e fluxos alternativos foram tratados ou explicitamente apontados?
- [ ] As lacunas ou dúvidas foram registradas de forma clara para o usuário?
- [ ] A saída final respeita o molde especificado em `assets/templates/`?
