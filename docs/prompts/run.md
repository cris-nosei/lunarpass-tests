# Execução de Teste com Playwright MCP

Acesse `http://localhost:3000` e execute o cenário **"Buscar missões para todas as bases lunares disponíveis"**, conforme documentado em `docs/storefront.md`.

**Condições obrigatórias:**

- Utilize exclusivamente o **Playwright MCP** em todas as etapas da execução.
- Execute o navegador em modo **não Headless** (`headless: false`).
- Não utilize CURL, chamadas HTTP diretas ou qualquer ferramenta alternativa ao Playwright MCP.
- Siga fielmente os passos e resultados esperados descritos na documentação.
